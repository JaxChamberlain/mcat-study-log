# MCAT Study Log

A study tracker for the May 7, 2027 MCAT: countdown, week-by-week UWorld and AAMC plan, study log, practice-test scores, and content checklist.

- `mcat-tracker.html`: the app. It's the same file the Claude artifact uses.
- `build.js`: run `node build.js` after editing `mcat-tracker.html` to rebuild `site/index.html`.
- `site/`: what Vercel serves (set the Vercel project's Root Directory to `site`).
- `supabase-setup.sql`: the database table and its security rules, run once in Supabase.
